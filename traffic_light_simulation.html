Data Structures & Algorithmic Design

How FIFO queues power signal optimization in this simulation

1. Custom FIFO Queue (`TrafficQueue`)

Each directional approach (North, South, East, West) operates an isolated First-In, First-Out Queue data structure. Vehicles enqueue upon reaching the deceleration zone and dequeue sequentially only when the corresponding directional light is Green.

2. Adaptive Queue-Aware Optimization Algorithm

Unlike standard fixed-timer controllers, the Adaptive Controller continuously evaluates queue lengths: Length(N) + Length(S) vs Length(E) + Length(W). If the pending queue depth exceeds the threshold during an active phase, the controller dynamically grants bonus green time to drain congestion before cycling.

3. Emergency Vehicle Priority Interrupt

When an emergency vehicle is dispatched, it injects directly into the queue head. The Finite State Machine (FSM) instantly triggers a rapid yellow warning on conflicting axes and immediately activates an emergency green hallway for the priority vehicle.
